# README images

The top-level README uses these. To swap a placeholder for a real photo or
GIF, drop the file in here and update the matching `<img src>` in
`README.md`. A `.jpg`, `.png` or `.gif` works; keep each file under about
5 MB so the page loads quickly.

| File | Used for | What to shoot |
|---|---|---|
| `hero.svg` | Banner at the top | An animated rainbow wordmark, drawn in SVG. Keep it, or replace it with `hero.gif`: a matrix and a ring running an effect on a dark background, in a 3-second loop, about 1600×460. |
| `first-light.svg` | Next to the code sample | A photo of the ESP32-C6 DevKit, or a short strip, lit blue on a desk. About 800×560. |
| `gallery-ring.svg` | Gallery | A ring spinning a comet (a GIF is best). |
| `gallery-matrix.svg` | Gallery | A matrix scrolling text. This one waits for `ledkit-layout`. |
| `gallery-wiring.svg` | Gallery | A Teensy 4, a 74AHCT125 and a strip on a breadboard, shot from above. |

Tips: shoot LEDs at low brightness (20% or less) so the colors don't blow out
to white, use a dark background, and turn off auto-exposure if your camera
lets you.
