# X11 misc-fixed fonts

Bitmap fonts from the X.Org `misc-misc` collection
(<https://gitlab.freedesktop.org/xorg/font/misc-misc>), by Markus Kuhn and
others. Each file says: "Public domain font. Share and enjoy."

These copies keep only the printable ASCII characters (space to `~`); the
headers are unchanged apart from the character count. They were taken from the
copies shipped with the `embedded-graphics` 0.8 crate.

They feed the [text preview page](../../../site/text-preview/), and will feed
ledkit's own text support.
