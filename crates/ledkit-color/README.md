# ledkit-color

Colors for addressable LEDs (NeoPixel, DotStar and friends): RGB and RGBW,
hue, gamma correction, color temperature and gradients. `no_std`, no
allocator.

Part of [ledkit](https://github.com/jrowe88/ledkit). Full documentation and
examples are coming with the first release.
